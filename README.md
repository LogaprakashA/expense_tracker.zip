# Expense Tracker Web Application

A simple expense tracker built using Python Flask and SQLite.

## Features
- Add daily expenses
- View all expenses
- Automatic total calculation

## Technologies Used
- Python
- Flask
- SQLite
- HTML & CSS

## How to Run
1. Install Flask  
   `pip install flask`
2. Run the app  
   `python app.py`
3. Open browser  
   http://127.0.0.1:5000
